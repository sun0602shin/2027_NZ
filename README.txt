Little Routes v1.1.0

배포: index.html, sw.js, manifest.webmanifest, icon.svg 파일을 같은 GitHub Pages 폴더에 올려주세요. HTTPS로 한 번 열면 이후 오프라인 앱 실행이 가능합니다. 파일로 직접 열면 Service Worker가 작동하지 않습니다.

기존 v1.0.0과 동일한 웹 주소/브라우저 저장소를 사용해야 저장된 일정이 유지됩니다. 배포 전 v1.0.0에서 JSON 백업을 받으세요. v1.1.0에서 기존 JSON을 복원할 수 있습니다.

식당 추천은 OpenStreetMap 공용 서비스에 의존해 네트워크·쿼터에 따라 실패할 수 있고, 영업 여부·평점은 제공하지 않습니다. 장소 기준 검색 결과 중 가까운 3곳을 후보로 저장합니다.

바우처 파일은 기기 IndexedDB에 저장됩니다. 전체 백업(첨부 포함)으로 별도 보관하세요.
